☁️ Day 1 – Foundations of the Cloud Domain 1

What is Cloud Computing?

Cloud computing is the on-demand provision of IT resources (compute, storage, databases, networking, software) via the internet on a pay-as-you-go basis (pay-as-you-go).

The 6 Advantages of the Cloud (AWS)

  • Trade fixed expense for variable expense – You only pay for what you use
  • Benefit from massive economies of scale – AWS aggregates millions of customers
  • Stop guessing capacity – Scale up/down based on demand
  • Increase speed and agility – Resources ready in minutes
  • Stop spending money running data centers – Focus on business, not infrastructure
  • Go global in minutes – Deploy to multiple Regions with just a few clicks

🌐 Day 2 – Global Infrastructure Domains 1 & 3

How to Choose an AWS Region?

  • Compliance & Data Residency: Local laws (e.g. GDPR imposes data in the EU)
  • Latency: Choose the Region closest to your users
  • Availability of Services: Not all AWS services are in all Regions
  • Costs: Prices vary between Regions (us-east-1 often cheaper)

Least Privilege Principle

Only grant permissions that are strictly necessary to perform the work. Start with zero permissions and add only those needed.

Practice: Use AWS Access Analyzer to identify excessively accessed resources. Use IAM Access Advisor to see recent logins and remove unused permissions.

AWS Global Accelerator

Improve global application availability and performance using the private AWS backbone network (not the public internet).

  • Provides 2 static anycast IPs global as a fixed point of entry
  • Traffic enters the AWS network at the nearest Edge Location and travels over the AWS backbone
  • Supports EC2, ALB, NLB, Elastic IP as endpoints
  • Automatic health checks: failover in <30 seconds if endpoint is unhealthy
Global Accelerator vs CloudFront: CloudFront = CDN (static/dynamic content cache). Global Accelerator = accelerates non-HTTP TCP/UDP traffic (gaming, IoT, VoIP) or apps that require fixed IPs.

Disaster Recovery – 4 Strategies

RPO (Recovery Point Objective) = how much data can be lost (e.g. backup every 1h = RPO max 1h).
RTO (Recovery Time Objective) = how long to get back up and running after a disaster.

DR StrategyRPORTOConstDescription
Backup & RestoreHigh (hours)High (hours)💲Backup to S3/Glacier. Restore when needed. Cheap but slow.
Pilot LightMediumMedium (minutes)💲💲Minimum core always active (e.g. replicated DB). Quick scale-out in DR case.
Warm StandbyBassLow (minutes)💲💲💲Reduced version of the always running environment. Scale-up in DR case.
Multi-Site / Hot StandbyMinimumMinimum (seconds)💲💲💲💲Two full-scale environments in parallel. Instant failover. Higher cost.
Mnemonic: Backup→Pilot→Warm→Hot: cost goes up, RPO/RTO goes down. The more you spend, the sooner you get back.

👶 AWS in Plain English TL;DR

How to memorize AWS services for the exam by associating them with simple everyday concepts.

Amazon EC2

A computer (server) for rent in the cloud. You pay by the hour or second.

Amazon S3

An infinite hard drive on the internet. You put files (objects) in it and it never runs out of space.

Amazon RDS

A database managed by AWS. You put data in it, they do the backups and updates.

AWS IAM

The bouncer of your AWS account. Decides who can enter and what they can do.

Amazon VPC

Your private fence in the cloud. You put your servers inside it to isolate them from the internet.

AWS Lambda

Run your code without having to manage any servers. You only pay for the milliseconds it runs.

Amazon Route 53

The phone book of the internet (DNS). Translates "google.com" into its IP address.

Amazon CloudFront

A network of fast delivery drivers. They save copies of your site around the world to load it faster.

Amazon SNS

A megaphone. You send a message and everyone subscribed (email, SMS) receives it instantly.

Amazon SQS

The line at the post office. Messages wait their turn in a queue until someone processes them.

AWS CloudFormation

A recipe or an architectural blueprint. You write what you want and it builds everything automatically.

AWS Elastic Beanstalk

A vending machine. You insert your app code and it creates servers, network, and load balancer for you.

Amazon CloudWatch

The dashboard of the car. It shows you the speed (metrics) and sounds the alarm if something goes wrong.

AWS Auto Scaling

A thermostat. Adds more servers if there is too much traffic, and turns them off when they are no longer needed.

Amazon DynamoDB

Super fast database that doesn't use fixed tables (NoSQL). Great for games and fast apps.

AWS CloudTrail

The security cameras of the account. Records "who did what" for audits.

AWS Organizations

Allows you to manage many AWS accounts as a single large company with a single bill.

Elastic Load Balancer (ELB)

The traffic cop. Routes incoming traffic across various EC2 servers so that none gets overloaded.

Amazon Athena

Allows you to search and analyze files saved in S3 using a standard language (SQL) without servers.

Amazon Redshift

The huge data warehouse for heavy market analysis.

AWS Trusted Advisor

The automatic consultant. Advises you on how to save money, be more secure, and faster on AWS.

Amazon GuardDuty

The smart watchdog (ML) that sniffs out hackers or attacks in your account.

AWS WAF & Shield

The website shields. Block common hackers (WAF) and attacks that try to take down the site (Shield).

Amazon Macie

Searches your files on S3 to find top-secret documents or personal data using Machine Learning.

AWS Cost Explorer

Shows graphs of how much you are spending on AWS and forecasts how much you will spend in the coming months.

Amazon EFS

A shared hard drive (File System) that can be read and written by many Linux servers simultaneously.

Amazon EBS

The hard drive (Block Storage) attached to a single EC2 server. Fast and reliable.

AWS Snowball

A giant reinforced suitcase that AWS ships to your home to copy Terabytes of data offline.

🪤 Trick Questions – 10 Hard Questions

These questions cover the most frequently failed points in the CLF-C02 exam. Select the answer and click "Verify".

1. A company must ensure that its database remains available even if an entire Availability Zone becomes inaccessible. Which RDS feature should it enable?
✅ Answer: B – RDS Multi-AZ
Multi-AZ creates a synchronous standby replica in a different AZ with automatic failover (60-120 seconds). The Read Replica is asynchronous and is used to scale reads, not for automatic failover.
2. A Security Group allows inbound traffic on port 443. A NACL blocks outbound traffic on port 443 to the same subnet. What happens to inbound HTTPS connections?
✅ Answer: B – Blocked by NACL
NACL is stateless: each packet is evaluated independently. Even if the inbound connection is allowed, the outbound response traffic is blocked by the NACL. Security Groups are stateful: they track the connection state and automatically allow response traffic.
3. A team must archive legal compliance logs for 7 years. The logs will never be read but must be retrievable within 48 hours if necessary. Which S3 class is the most cost-effective?
✅ Answer: C – S3 Glacier Deep Archive
It is the most cost-effective S3 class (~$0.00099/GB/month). The 12-48 hour retrieval meets the requirement. Standard-IA and Glacier Flexible cost more. Standard is the most expensive for rarely accessed long-term storage.
4. An EC2 application needs to read files from an S3 bucket. What is the BEST method to grant this access securely?
✅ Answer: B – IAM Role on the EC2 instance
Roles provide temporary and automatically rotating credentials via Instance Metadata Service. You should never hard-code access keys in code (risk of leak). Root credentials should never be used in applications.
5. What is the main difference between AWS CloudTrail and AWS Config?
✅ Answer: B
CloudTrail = audit trail of ALL API calls (who, what, when, from where). Config = state and history of resource configuration + compliance rules. Examples: CloudTrail says "who terminated the EC2 instance at 14:30"; Config says "this instance did not have Multi-AZ enabled".
6. A company with 20 AWS accounts wants to apply a policy that prevents ALL accounts (including the management account) from disabling CloudTrail. Which service to use?
✅ Answer: C – SCP on the Root
AWS Organizations SCPs apply maximum permissions to the entire hierarchy. Applied to the Root, it extends to all OUs and accounts. IAM Policies only operate within a single account. Config Rules detect non-compliance but do not prevent it.
7. An organization with 15 AWS accounts uses Consolidated Billing. It purchased 100 m5.large Reserved Instances. Only one of the 15 accounts actually uses those instances. How does the RI discount work?
✅ Answer: B – Automatic sharing
With Consolidated Billing, Reserved Instances and Savings Plans are automatically shared across all accounts in the Organization (if RI Sharing is enabled, which is the default). This maximizes the use of discounts. This is one of the main benefits of Consolidated Billing.
8. An application must process 1 million images uploaded to S3 every day. Processing takes 2 minutes per image. Which service is most appropriate?
✅ Answer: D – Lambda is not suitable
Lambda has a maximum timeout of 15 minutes. 2 minutes is under the limit, however with 1 million images/day (~11.5/sec) and the batch nature of the work, EC2+ASG+SQS or Fargate+ECS+SQS are more appropriate for sustained batch workloads. Lambda is ideal for short event-driven tasks.
9. Which statement about the shared responsibility model for Amazon RDS is CORRECT?
✅ Answer: B
RDS is a managed service: AWS manages OS patching, DB engine patching, automated backups, hardware Multi-AZ failover. The customer is responsible for data, queries, access configuration (DB users, Security Groups), and choosing backup/retention options.
10. A company wants to reduce EC2 costs for stable, predictable production workloads running 24/7 for the next 3 years. Which purchasing option offers the MAXIMUM savings?
✅ Answer: C – Reserved Instances 3 years All Upfront
For stable 24/7 workloads over 3 years, 3yr All Upfront RIs offer up to a 72% discount compared to On-Demand. Spot is not suitable for production (interruptible). Dedicated Hosts are more expensive and used for compliance/BYOL. Savings Plans are flexible but slightly less cost-effective than RIs for the same instance types.
