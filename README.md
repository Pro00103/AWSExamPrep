AWS Certified Cloud Practitioner (CLF-C02) - Ultimate Study Guide ☁️
Benvenuto nella Ultimate Study Guide per l'esame AWS Certified Cloud Practitioner (CLF-C02). Questa applicazione web statica (Single Page Application) è stata progettata per offrire un'esperienza di studio completa, interattiva e bilingue (Italiano e Inglese).

🚀 Caratteristiche Principali (Features)
Piano di Studio in 10 Giorni: Un percorso strutturato che copre tutti e 4 i domini dell'esame AWS CLF-C02, dalle basi del Cloud Computing fino ai concetti avanzati di Security, Architettura e Pricing.
+1200 Flashcard Interattive: Ripassa i concetti chiave in modo rapido ed efficace. Le flashcard possono essere filtrate per dominio, lette in modalità studio o testate con le statistiche di completamento automatico (Mastery).
Simulatore d'Esame: Mettiti alla prova con simulazioni d'esame e le insidiose "Domande Trappola" (Quiz Trappole), pensate per evitare gli errori più comuni.
Completamente Bilingue (IT / EN): Passa dall'italiano all'inglese istantaneamente con un semplice clic. Perfetto per chi studia nella propria lingua madre ma vuole prepararsi con la terminologia d'esame ufficiale inglese.
Dark Mode: Interfaccia moderna con supporto per la modalità chiara e scura.
Nessun Backend Richiesto: I dati risiedono localmente nel file Javascript. La privacy è totale e i progressi delle flashcard vengono salvati direttamente nel Local Storage del tuo browser.
💻 Come Utilizzare il Progetto
Poiché il sito è una semplice app HTML/CSS/JS, non è necessaria alcuna installazione con Node.js o Python.

Clona questo repository o scarica i file.
Apri index.html (versione Italiana) o aws_study_guide_en_V2.html (versione Inglese) in un qualsiasi browser moderno (Chrome, Firefox, Safari, Edge).
Inizia a studiare!
📁 Struttura dei File
index.html: La landing page principale, contenente il layout, lo stile e l'intero piano di studi tradotto in italiano.
aws_study_guide_en_V2.html: La versione speculare del sito tradotta interamente in lingua inglese.
exam_data.js: Il database dei contenuti. Contiene tutte le flashcard, i quiz e la struttura dei dati che viene iniettata dinamicamente nelle due pagine HTML.
🌐 Deployment (GitHub Pages)
Questo progetto è ottimizzato per essere ospitato gratuitamente su GitHub Pages.

Carica i 3 file principali (index.html, aws_study_guide_en_V2.html, exam_data.js) in questo repository.
Vai su Settings > Pages.
Seleziona il branch main come Source e clicca Save.
Attendi 1-2 minuti. Il tuo sito sarà live e pronto per essere utilizzato!
